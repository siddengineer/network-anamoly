# Datasets Directory

This directory stores uploaded and benchmark network traffic datasets for NetGuard AI.

## Benchmark Dataset
- **File**: `CIC-IDS2017.xlsx`
- **Rows**: 1,000 network flows
- **Features**:
  1. `Destination Port`
  2. `Flow Duration`
  3. `Total Fwd Packets`
  4. `Total Backward Packets`
  5. `Total Length of Fwd Packets`
  6. `Total Length of Bwd Packets`
  7. `Fwd Packet Length Max`
  8. `Fwd Packet Length Min`
  9. `Fwd Packet Length Mean`
  10. `Fwd Packet Length Std`
  11. `Label` (BENIGN, DoS Hulk, DDoS, PortScan, FTP-Patator, SSH-Patator)
